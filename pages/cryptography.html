02

CIA Triad & Cryptography

Cryptography plays an important role in confidentiality, integrity and authentication.

Confidentiality

Encryption prevents unauthorized users from reading sensitive information.

Integrity

Hashing and digital signatures help detect unauthorized changes to information.

Authentication

Digital certificates and signatures help verify the identity of communicating parties.

Non-Repudiation

Digital signatures provide evidence that a message or transaction was created by its signer.

03

Types of Cryptography

The three fundamental approaches are symmetric encryption, asymmetric encryption and hashing.

Symmetric Cryptography

Uses the same secret key for encryption and decryption.

  • Fast processing
  • Suitable for large data
  • AES is a common example

Asymmetric Cryptography

Uses a pair of mathematically related public and private keys.

  • Public key
  • Private key
  • RSA and ECC

Hashing

Converts data into a fixed-length value and is designed as a one-way process.

  • SHA-256
  • SHA-3
  • Integrity verification

Asymmetric Encryption

Asymmetric cryptography uses a public key and a private key for secure communication.

Public Key

Can be shared openly and is used for encryption or signature verification.

Private Key

Must remain secret and is used for decryption or creating digital signatures.

Common Algorithms

RSA, ECC and Diffie-Hellman are commonly associated with public-key cryptography.

Symmetric vs Asymmetric

Digital Signatures

Digital signatures help provide authentication, integrity and non-repudiation.

1. Create Hash

A hash is generated from the original message.

2. Sign with Private Key

The sender uses a private key to create the digital signature.

3. Verify with Public Key

The receiver uses the public key to verify the signature.

Public Key Infrastructure (PKI)

PKI provides the infrastructure used to manage digital certificates and public keys.

Certificate Authority

A trusted authority that issues and manages digital certificates.

Digital Certificate

Binds an identity to a public key and is signed by a trusted certificate authority.

Certificate Chain

A chain of trust connecting certificates to a trusted root authority.

Common Cryptographic Attacks

Understand common attacks against weak cryptographic implementations.

Brute Force Attack

Attempts many possible keys or passwords until the correct one is discovered.

Dictionary Attack

Uses a prepared list of likely passwords or keys.

Rainbow Table Attack

Uses precomputed hash values to help recover weak password hashes.

Collision Attack

Attempts to find different inputs that produce the same hash value.

Man-in-the-Middle

An attacker attempts to intercept or manipulate communication between parties.

Weak Key Attack

Exploits predictable, short or poorly generated cryptographic keys.

Cryptography Interview Questions

Test your understanding of important cryptography concepts.

What is cryptography?

Cryptography is the practice of protecting information using mathematical algorithms, keys and security techniques.

What is encryption?

Encryption transforms readable plaintext into ciphertext so unauthorized users cannot easily understand the original information.

What is the difference between encryption and hashing?

Encryption is designed to be reversible with the appropriate key, while cryptographic hashing is designed as a one-way transformation.

What is symmetric encryption?

Symmetric encryption uses the same shared secret key for encryption and decryption.

What is asymmetric encryption?

Asymmetric cryptography uses a public key and a private key.

What is AES?

AES is a widely used symmetric block cipher available with 128-bit, 192-bit and 256-bit key sizes.

What is RSA?

RSA is a public-key cryptographic algorithm commonly associated with encryption, key exchange and digital signatures.

What is SHA-256?

SHA-256 is a member of the SHA-2 family of cryptographic hash functions that produces a 256-bit hash value.

What is a digital signature?

A digital signature is a cryptographic mechanism used to provide authentication, integrity and non-repudiation.

What is PKI?

Public Key Infrastructure is the collection of technologies, policies and authorities used to manage public-key certificates.

What is TLS?

TLS is a cryptographic protocol used to protect communication over networks.

Why is cryptography important in cybersecurity?

Cryptography helps protect confidentiality, integrity, authentication and secure communication.
