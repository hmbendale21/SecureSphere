Linux File System

Linux organizes files and directories using a hierarchical structure.

/

Root directory. The starting point of the Linux file system.

/home

Contains personal directories belonging to users.

/etc

Contains system-wide configuration files.

/var

Stores variable data such as logs and application data.

/proc

Virtual file system containing process and kernel information.

/bin

Contains essential executable programs and commands.

Linux File Permissions

Linux permissions control who can read, modify and execute files and directories.

Understanding rwx

Every file and directory has permissions for three categories of users: Owner, Group and Others.

Owner rwx Read · Write · Execute
Group rwx Read · Write · Execute
Others r-x Read · Execute
r

Read

Allows viewing the contents of a file.

4
w

Write

Allows modifying the contents of a file.

2
x

Execute

Allows executing a file or entering a directory.

1

chmod

Change file or directory permissions.

chmod 755 script.sh
7 Owner 5 Group 5 Others

755 means the owner can read, write and execute, while group and others can read and execute.

chown

Change file ownership.

sudo chown user:filegroup report.txt

Ownership controls which user and group are associated with a file.

chgrp

Change the group ownership of a file.

sudo chgrp security report.txt

Common Numeric Permissions

Permission Meaning Example
777 Read, write and execute for everyone rwxrwxrwx
755 Owner full access; others read/execute rwxr-xr-x
644 Owner read/write; others read rw-r--r--
600 Owner read/write only rw-------

Why Permissions Matter in Cybersecurity

Incorrect permissions can expose sensitive files, allow unauthorized modification or give attackers unnecessary privileges.

Processes & System Monitoring

Learn how to view running processes, monitor system resources and identify unusual activity.

What is a Process?

A process is a running instance of a program. Linux assigns each process a unique Process ID (PID) and manages its CPU, memory and other resources.

ps

ps aux

Displays currently running processes and information such as CPU and memory usage.

top

top

Provides a real-time view of processes and system resource usage.

htop

htop

An interactive process viewer that makes process monitoring easier.

kill

kill PID

Sends a signal to a process, commonly to request termination.

free

free -h

Displays available and used system memory.

df

df -h

Shows available and used disk space on mounted file systems.

uptime

uptime

Shows how long the system has been running and its load information.

systemctl

systemctl status ssh

Manages and checks services on systems using systemd.

🔎 Important Process Information

PID

Why Process Monitoring Matters

Security analysts can inspect running processes to identify unexpected applications, unusual resource consumption or suspicious activity.

Linux Shell Scripting

Automate repetitive tasks and system operations using shell scripts.

What is Shell Scripting?

A shell script is a text file containing a sequence of commands that can be executed by a shell. Bash is one of the most commonly used shells on Linux.

basic.sh
Bash 
#!/bin/bash

echo "Welcome to SecureSphere"

name="Himanshu"

echo "Hello $name"

Variables

name="Linux"

Store values that can be reused throughout a script.

Conditions

if [ "$x" -gt 5 ]

Execute different commands depending on whether a condition is true.

Loops

for file in *.log

Repeat commands for multiple values, files or tasks.

Functions

function_name() { ... }

Organize reusable commands into logical blocks.

⚡ Useful Shell Script Examples

Shell Scripting in Cybersecurity

Security professionals use shell scripts to automate repetitive tasks such as log processing, system checks, file monitoring and basic security administration.

Linux Security & Hardening

Learn the basic practices used to protect Linux systems from unauthorized access and common threats.

What is Linux Hardening?

Linux hardening is the process of reducing unnecessary security risks by securing accounts, permissions, services, network access and system configuration.

User Management

Create only required accounts and avoid unnecessary privileged access.

whoami

Least Privilege

Give users and applications only the permissions required to perform their tasks.

sudo -l

Secure SSH

Use strong authentication and restrict unnecessary remote access.

systemctl status ssh

Firewall

Restrict unwanted network traffic and expose only required services.

ufw status

Security Updates

Keep the operating system and installed software updated with security fixes.

sudo apt update

Services

Disable unnecessary services to reduce the system's attack surface.

systemctl --type=service

🛡 Linux Hardening Checklist

Use strong authentication
Remove unnecessary users
Apply security updates
Restrict file permissions
Disable unnecessary services
Configure firewall rules
Monitor system logs
Minimize privileged access

⚡ Useful Security Commands

Check current user whoami
Check privileges sudo -l
Check listening ports ss -tuln
Check firewall sudo ufw status
Check services systemctl --type=service

Security Principle

A secure Linux system should expose only the services, ports and permissions that are actually required. This reduces the overall attack surface.
