# 🛡️ SecureSphere

### AI-Powered Cybersecurity Portal

SecureSphere is a web-based cybersecurity portal that combines **security tools, password analysis, cybersecurity learning, threat awareness, and cyber news** in one platform.

🌐 **Live Demo:** [🟢 SecureSphere](https://securespherehb.vercel.app/)

---

## ✨ Features

- 📊 **Security Dashboard** – Security score, threat level, system status and security metrics
- 🔐 **Password Tools** – Password generator, passphrase generator and password analyzer
- 🛠️ **Security Tools** – Hash generator, file hashing, Base64 and URL tools
- 📚 **Cybersecurity Learning** – Networking, Cryptography, Ethical Hacking, Cloud Security, Linux, OWASP and AI in Cybersecurity
- 📰 **Cyber News** – Cybersecurity news, categories, search and bookmarks
- 🏆 **Certifications** – Cybersecurity certification guidance
- 📩 **Contact** – Project communication and feedback
- 📱 **Responsive Design** – Works across desktop, tablet and mobile
